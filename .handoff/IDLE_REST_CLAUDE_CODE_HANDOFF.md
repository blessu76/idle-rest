## 3. 디자인 방향

### 브랜드

- 서비스명: `idle()`
- 상위 브랜드: `ipe()`
- 슬로건: `ipe(); // be still`
- 분위기: 개발자의 idle time, 조용한 쉼, 늦은 밤의 로파이, 따뜻하지만 과장되지 않은 위로
- 폰트: 모노스페이스 중심. 가독성이 필요한 한국어 본문에는 시스템 산세리프를 보조로 사용

### 색상 토큰

```css
--navy: #0D1117;
--gold: #C9A84C;
--sage: #8FAF8F;
--cream: #F5F0E8;
```

이 토큰을 기반으로 다크·라이트·세피아·앰비언트 테마를 CSS custom properties로 구성한다. 색상값을 컴포넌트마다 하드코딩하지 않는다.

### 레이아웃

- 모바일 우선으로 설계하되 데스크톱에서는 단순 확대가 아닌 넓은 화면에 맞는 2열 또는 카드 그리드를 사용한다.
- 히어로에서 `idle()` 정체성, 현재 시간대 인사, 대표 음악을 한눈에 이해하게 한다.
- 대표 앨범/플레이어, 무드 선택, 싱글·앨범 카드, 앱 소개, 웹사이트/브랜드 정보를 명확한 섹션으로 구분한다.
- 카드, 테두리, 여백은 조용하고 정돈된 리듬을 유지한다.
- 과도한 그림자, 네온, 유리 효과는 피한다.

## 4. 핵심 화면 및 기능

### 상단/히어로

- `idle()` 로고와 `ipe() // be still` 브랜드 문구를 시각적으로 구분한다.
- 우측에 플레이리스트 아이콘과 설정 아이콘을 둔다.
- 시간대별 인사와 상태 문구를 한 줄 구조로 정돈한다.
- 예: `좋은 저녁이에요` + 우측 정렬 `// 지금은 - 노곤한 저녁`
- 앱 홈 화면에서 제거하기로 한 테마 선택 버튼은 웹에서도 헤더를 과밀하게 만들지 않도록 설정 영역 또는 별도 컨트롤로 정리한다.

### 음악/앨범

- 대표 앨범 `dear you`를 가장 중요한 카드로 보여준다.
- 곡/앨범 카드에는 커버, 제목, 설명, 곡 수, 재생 버튼을 제공한다.
- 재생 버튼은 충분히 크고 명확한 접근성 이름을 가져야 한다.
- 플레이리스트 진입 버튼은 하단에서도 눈에 띄게 하고 헤더에도 빠른 진입 아이콘을 둔다.

### 무드

- `늦은 밤`, `집중`, `쉼`, `새벽` 등 현재 음악 분류를 유지한다.
- 텍스트 라벨과 코드 스타일 보조 라벨을 함께 사용하되, 모바일에서 줄바꿈이 어색하지 않아야 한다.

### 앱 소개

- 첨부된 최종 앱 아이콘(`idle-app-icon.png`)을 사용한다.
- iOS 앱으로 이어지는 영역은 사이트 안에서 자연스러운 프로모션 카드로 처리한다.

### 푸터

- `© 2026 ipe studio`
- 하단 중복 문구 `// be still`은 카피라이트가 있으므로 제거한다.
- 웹사이트 주소 `https://idle.ipe.rest`와 필요한 정책/연락 링크를 정돈한다.

## 5. 반응형 기준

- 모바일: 320px 이상, 한 열 카드, 터치 타깃 최소 44px
- 태블릿: 768px 전후, 정보 밀도를 조금 높이고 카드 2열 허용
- 데스크톱: 1024px 이상, 히어로/플레이어와 보조 콘텐츠를 2열 또는 명확한 그리드로 구성
- 최대 콘텐츠 폭을 두고 초대형 화면에서 지나치게 늘어나지 않게 한다.
- 가로 스크롤이 없어야 한다.
- iOS safe-area를 고려한다.

## 6. GEO·SEO·JSON-LD

페이지에 보이는 실제 콘텐츠와 일치하도록 JSON-LD를 구성한다. JSON-LD만 늘리고 화면 콘텐츠가 빈약한 구조는 금지한다.

최소 권장 스키마:

- `WebSite`
- `Organization`
- `MusicGroup` 또는 브랜드 특성에 맞는 엔터티
- `MusicAlbum`
- `MusicRecording`
- `ItemList` 또는 플레이리스트
- `SoftwareApplication` (`idle()` 앱)
- `BreadcrumbList`가 실제 탐색 구조와 맞을 때만 사용

요구사항:

- 모든 JSON-LD는 파싱 가능한 유효 JSON이어야 한다.
- URL은 canonical과 일치시킨다.
- 다국어 alternate/hreflang이 기존에 있다면 보존·정리한다.
- `robots.txt`, `sitemap.xml`, `llms.txt`, manifest, service worker가 있다면 기존 역할을 보존하면서 최신 경로로 정리한다.
- 문서 제목, description, OG/Twitter 카드, canonical을 점검한다.

## 7. 접근성·성능

- 시맨틱 HTML과 올바른 heading 순서를 사용한다.
- 아이콘 단독 버튼에는 `aria-label`을 제공한다.
- 키보드 포커스가 명확해야 한다.
- 라이트/다크 모든 테마에서 WCAG AA 수준의 텍스트 대비를 지향한다.
- 이미지에 width/height 또는 aspect-ratio를 지정해 CLS를 줄인다.
- 초기 화면 외 이미지는 lazy loading한다.
- JS가 비활성화돼도 주요 소개와 음악 목록을 읽을 수 있게 한다.
- 불필요한 프레임워크 추가를 피하고 기존 기술 스택 안에서 구현한다.
