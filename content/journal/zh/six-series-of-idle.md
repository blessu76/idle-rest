如果你浏览 idle() 的歌曲列表，会看到几个陌生的名字：`late_night.lofi`、`rest() { chill(); }`、`undefined → known`。它们不是歌名，而是把歌曲归在一起的名字，我们称之为系列。本文说明什么是系列、读懂这些名字的一种方式，以及歌曲编号和专辑如何与系列联系起来。

先坦率说明几点。本文依据的是网站上已经公开的信息和我们的歌曲编号规则。每个名字最初是怎么定下来的，没有任何记录，所以我们不讲这段故事。下面的读法借用了以读代码为日常的人的习惯，只是解读，并不是在说明命名的本意。另外，一如既往：音乐由 AI（Suno）制作。歌词由 AI 起草，并经人工审阅。

## 系列是歌曲的氛围标签

![六张卡片，每个系列一张。late_night.lofi 是 lo-fi，be still; 是治愈，rest() { chill(); } 是 chill，grace_in_the_loop 是氛围乐，undefined → known 是 lo-fi，night_mode // not_alone 是治愈。late_night.lofi 和 undefined → known 的卡片带有标记，表示已发行单曲](/assets/journal/six-series-of-idle/six-series.jpg)

*网站上公开的六个系列。曲风与主题均取自网站自己的简介；金色轮廓表示该系列已有单曲发行。*

系列是曲风与感受的名牌，一个短语就能告诉你这首歌用什么声音制作，希望传达怎样的氛围。网站上公开的六个系列如下：

- `be still;`：治愈，主题是静止
- `late_night.lofi`：lo-fi，熬夜之后回家的路上
- `rest() { chill(); }`：chill，今天已经做得够多了
- `grace_in_the_loop`：氛围乐，重复之中的恩典
- `undefined → known`：lo-fi，未知变为已知的那一刻
- `night_mode // not_alone`：治愈，献给觉得孤单的夜晚

到目前为止，有两个系列已经出了歌。`late_night.lofi` 发行了单曲 “still compiling”，`undefined → known` 发行了 “good morning, world”。在这六个之外，`dear(you);` 被用作专辑名，成为一张十首歌的专辑。其余四个系列只公开了名字和主题，还没有歌曲发行，所以这里不多说。

## 像读代码一样读名字

这六个名字有一个共同点：都像是编程语言的语法。下面逐一给出一种读法，不需要是开发者也能跟上。这是一种读法，并不能证明这些名字想表达什么。

`late_night.lofi` 看起来像文件名。点号后面是扩展名，而扩展名就是曲风。你可以把它读成：打开一个叫“深夜”的文件，里面是 lo-fi。网站的简介把单曲 “still compiling” 描述为献给那个没等构建完成就走不开的夜晚的 lo-fi。

`be still;` 是以分号结尾的一行。在许多语言里，分号表示一条语句的结束。要你静下来的指令到此为止，没有什么需要补充。主题是静止。

`rest() { chill(); }` 是一个函数。在名为 rest 的函数体内，调用了另一个名为 chill 的函数。它读起来像是在说：休息不是什么都不做，而是一项本身的工作，这项工作就是放松自在。这与它的主题很接近：今天已经做得够多了。

`grace_in_the_loop` 让人联想到循环。在代码里，循环会反复执行同样的工作，而开发者的一天很容易被重复填满。主题是在这种重复之中找到恩典。氛围乐这一曲风很合适：氛围乐更多是通过空间和质感而不是旋律来表达，相近的声音往往会持续很久。

`undefined → known` 对任何用过 JavaScript 的人来说一眼就懂。undefined 是值尚未被设定的状态，箭头标示它变成已知之物的那一刻。主题是未知变为已知的那一刻。网站把该系列的单曲 “good morning, world” 描述为明亮而充满希望的 lo-fi，而这个标题呼应了许多人初学编程时在屏幕上打印出的 “Hello, world”。

`night_mode // not_alone` 由两部分组成。前一部分是让屏幕变暗的设置的名字。后一部分的 `//` 在许多语言中表示注释的开始：写在代码旁边的一句轻声备注。你可以想象一块切换到夜间模式的屏幕，旁边有一条注释，说你并不孤单。

第一张专辑的命名用的是同样的语法。`dear(you);` 看起来像一个把 “you” 作为参数传入的函数调用，同时也是一封信的第一行，收信人写在括号里。品牌名 `ipe()` 和口号 `ipe(); // be still` 也是同样的读法。这个网站上的每一个名字，都是用同一种语言写成的。

## 如何读歌曲编号

![歌曲编号的说明：S1A1.03 读作第1季、第1张专辑、第3首曲目，而 U-001 和 N-001 是系列字母 U 或 N 加上顺序编号](/assets/journal/six-series-of-idle/song-codes.jpg)

*两种歌曲编号。专辑中的曲目有一个地址；独立发行的单曲则是系列字母加一个编号。*

系列也体现在歌曲编号里，有两种写法。属于专辑的歌曲有一个由季、专辑和曲目组成的三段式地址。第一张专辑的第三首歌是 S1A1.03：S1 是第1季，A1 是该季的第一张专辑，03 是这张专辑的第3首曲目。这个数字同时也是这首歌在专辑所讲述的故事中的位置。

尚未收入专辑的单曲，取其系列的首字母加一个顺序编号。`late_night.lofi` 的 N-001 和 `undefined → known` 的 U-001 就是例子。N 来自 night，U 来自 undefined。每个系列有一个前缀字母，所以只看编号就知道一首歌属于哪个系列。当单曲被收入专辑时，它的编号会改为专辑编号，而已经使用过的编号绝不会再次使用。

## 单曲如何成为专辑

![一张示意图：五首单曲通过箭头汇入专辑 dear(you); vol.1，这是第1季的第一张专辑，十首曲目从 S1A1.01 到 S1A1.10](/assets/journal/six-series-of-idle/singles-to-album.jpg)

*我们确定的方向：一首一首地发行单曲，等歌曲足够多了，再汇集成专辑。*

我们确定的发行方向是逐首发行单曲，等歌曲足够多时再汇集成专辑。*dear(you); vol.1* 就是以这种方式汇集的第一张专辑。它的十首歌都有英文版和韩文版，编号从 S1A1.01 到 S1A1.10。

歌曲一旦进入专辑，就有了地址，而这个地址也与一天中的时间相连。第1季把开发者的一天分成四张专辑：夜晚、黎明、早晨和傍晚。第一张专辑 *dear(you); vol.1* 对应的是睡前的夜晚。所以，当专辑编号改变时，你就来到了一天中的另一个时刻。

## 这些名字的用处

系列名有助于找到歌曲，但它更大的作用是设定预期。想找熬夜之后回家路上听的 lo-fi，可以打开 `late_night.lofi`。只想在今天好好休息的人，可以打开 `rest() { chill(); }`。我们设想中的听众是开发者和需要专注的人，希望一个可以用读代码的眼光去读的名字，能让人面对陌生的歌曲时少一点陌生感。最后这句话是我们的期望，而不是这些名字当初如何选定的记录在案的理由。
