idle() の曲リストを眺めていると、見慣れない名前がいくつか目に留まります。`late_night.lofi`、`rest() { chill(); }`、`undefined → known`。これらは曲のタイトルではありません。曲をまとめるための名前で、私たちはシリーズと呼んでいます。この記事では、シリーズとは何か、名前の読み方のひとつ、そして曲コードとアルバムがシリーズとどうつながっているかを説明します。

先にお断りしておきます。この記事は、サイトですでに公開されている情報と、曲番号のルールに基づいています。それぞれの名前が最初にどう決まったのか、その経緯はどこにも記録されていないため、語りません。以下の読み方は、コードを読み慣れた人の目線を借りた解釈であり、名前に込められた意図を述べるものではありません。そして、いつもどおり：音楽は AI(Suno)で制作しています。歌詞は AI が下書きし、人が確認しています。

## シリーズは曲のためのムードラベル

![シリーズごとに1枚、計6枚のカード。late_night.lofi はローファイ、be still; はヒーリング、rest() { chill(); } はチル、grace_in_the_loop はアンビエント、undefined → known はローファイ、night_mode // not_alone はヒーリング。late_night.lofi と undefined → known のカードには、シングルがリリース済みであることを示す印が付いている](/assets/journal/six-series-of-idle/six-series.jpg)

*サイトで公開されている6つのシリーズ。ジャンルとテーマはサイト自身の要約のとおりで、金色の枠はシングルが出ているシリーズを示します。*

シリーズは、ジャンルと気分につける名札です。その曲がどんな音で作られ、どんなムードに届きたいのかをひと言で伝えます。サイトに公開されている6つのシリーズは次のとおりです。

- `be still;`：ヒーリング、静けさがテーマ
- `late_night.lofi`：ローファイ、夜更かしのあとの帰り道
- `rest() { chill(); }`：チル、今日はもう十分やった
- `grace_in_the_loop`：アンビエント、繰り返しのなかにある恵み
- `undefined → known`：ローファイ、未知が既知になる瞬間
- `night_mode // not_alone`：ヒーリング、ひとりだと感じる夜のために

これまでに曲が出ているのは、そのうち2つです。`late_night.lofi` からはシングル「still compiling」が、`undefined → known` からは「good morning, world」がリリースされました。6つのリストの外では、`dear(you);` がアルバム名として使われ、10曲入りのアルバムになりました。残りの4つのシリーズは名前とテーマだけが公開されていて、リリースされた曲はまだないため、ここではそれ以上のことは述べません。

## 名前をコードのように読む

6つの名前には共通点があります。どれもプログラミング言語の構文に似ていることです。開発者でなくても楽しめるように、ひとつずつ読み方の例を挙げます。これは読み方であって、名前が何を伝えようとしたかの証明ではありません。

`late_night.lofi` はファイル名のように見えます。ドットの後ろは拡張子で、その拡張子がジャンルです。「late night」という名前のファイルを開くと、中にローファイが入っている、と読めます。サイトの要約は、シングル「still compiling」を、ビルドが終わるまで席を立てなかった夜のためのローファイと紹介しています。

`be still;` はセミコロンで終わる1行です。多くの言語で、セミコロンは文の終わりを示します。じっとしていなさいという指示が、そこで終わり、付け足すことは何もありません。テーマは静けさです。

`rest() { chill(); }` は関数です。rest という関数の本体のなかで、chill という別の関数が呼ばれています。休むことは何もしないことではなく、それ自体がひとつの仕事であり、その仕事とはくつろぐことなのだ、と読めます。テーマの「今日はもう十分やった」とも近い響きです。

`grace_in_the_loop` はループを思わせます。コードのなかでループは同じ作業を繰り返すもので、開発者の一日は繰り返しで埋まりがちです。テーマは、その繰り返しのなかに恵みがあるということ。ジャンルのアンビエントともよく合います。アンビエントはメロディよりも空間と質感で語る音楽で、似た音が長く続きやすいからです。

`undefined → known` は、JavaScript を使ったことがある人ならすぐに読めます。undefined は値が設定されていない状態で、矢印はそれが既知のものに変わる瞬間を示します。テーマは、未知が既知になる瞬間です。サイトは、このシリーズのシングル「good morning, world」を明るく希望に満ちたローファイと紹介していて、タイトルはプログラミングを習い始めたときに多くの人が画面に表示する「Hello, world」を思わせます。

`night_mode // not_alone` は二つの部分でできています。前半は、画面を暗くする設定の名前です。後半の `//` は多くの言語でコメントの始まりを示し、コードの横にそっと添えられたメモです。夜間モードに切り替えた画面と、その横に「ひとりじゃない」と書かれたメモを思い浮かべてみてください。

最初のアルバムの名前も、同じ文法で付けられています。`dear(you);` は「you」を引数として渡す関数呼び出しのようです。同時に、宛先をかっこの中に書いた手紙の最初の一行でもあります。ブランド名の `ipe()` とスローガンの `ipe(); // be still` も同じように読めます。このサイトのすべての名前は、ひとつの言語で書かれています。

## 曲コードの読み方

![曲コードの説明：S1A1.03 はシーズン1、アルバム1、トラック3と読み、U-001 と N-001 はシリーズの文字 U または N と通し番号で表す](/assets/journal/six-series-of-idle/song-codes.jpg)

*曲コードは2種類。アルバム収録曲には住所があり、単独のシングルにはシリーズの文字と番号があります。*

シリーズは曲コードにも現れ、書き方は2通りあります。アルバムに属する曲には、シーズン、アルバム、トラックの3つからなる住所が付きます。最初のアルバムの3曲目は S1A1.03 で、S1 はシーズン1、A1 はそのシーズンの最初のアルバム、03 はそのアルバムの3番目のトラックです。この番号は、アルバムが語る物語のなかでの、その曲の位置でもあります。

まだアルバムにまとめられていないシングルは、シリーズの頭文字と通し番号になります。`late_night.lofi` の N-001 と `undefined → known` の U-001 がその例です。N は night、U は undefined に由来します。各シリーズに頭文字がひとつずつあるので、番号だけでどのシリーズの曲かがわかります。シングルがアルバムに収められると、その番号はアルバムコードに移り、一度付けた番号は二度と再利用されません。

## シングルがアルバムになるまで

![5つのシングルが矢印でアルバム dear(you); vol.1 に合流する図。シーズン1の最初のアルバムで、10トラックが S1A1.01 から S1A1.10 まで並ぶ](/assets/journal/six-series-of-idle/singles-to-album.jpg)

*私たちが決めた方向：シングルをひとつずつリリースし、曲が十分にそろったらアルバムにまとめる。*

私たちが定めたリリースの方針は、シングルを一曲ずつ出し、曲が十分にたまったらアルバムにまとめるというものです。*dear(you); vol.1* は、そうしてまとめた最初のアルバムです。10曲すべてが英語版と韓国語版で公開されていて、コードは S1A1.01 から S1A1.10 まで続きます。

アルバムに入った曲には住所が付き、その住所は一日の時間帯とも結びついています。シーズン1は、開発者の一日を夜、明け方、朝、夕方の4枚のアルバムに分けています。最初のアルバム *dear(you); vol.1* が受け持つのは、眠る前の夜です。つまり、アルバムの番号が変わると、一日のなかの別の時間に移ることになります。

## これらの名前は何のためにあるのか

シリーズ名は曲を見つける助けになりますが、それより大きな役割は、期待を整えることです。夜更かしのあとの帰り道に合うローファイを探している人は `late_night.lofi` を開けます。今日はとにかく休みたい人は `rest() { chill(); }` を開けます。私たちが思い描いているリスナーは、開発者や集中が必要な人たちで、コードを読む目で読める名前なら、はじめての曲の前でも少しだけ違和感が和らぐのではないかと願っています。この最後の一文は私たちの願いであって、名前の付け方について記録された理由ではありません。
