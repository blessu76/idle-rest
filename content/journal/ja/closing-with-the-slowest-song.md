*dear(you); vol.1* の10曲目「You Did So Well Today.」(韓国語タイトル 「오늘도... 정말 고생했어.」)について、アルバム企画書と曲の設計書は、同じ言葉で紹介しています。10曲のなかでいちばん遅い、という言葉です。この曲は、すでに[問いかけで始まり、慰めで終わる](/journal/ja/open-with-a-question-close-with-comfort/)で最初の曲と対にして読みました。そこで述べたこと(Pre-Chorus の時制、「もう少し」の大きさ、窓、ささやきの順序)は、ここでは繰り返しません。この記事は向きを変えます。最後の曲を、その前の9曲すべてと並べて、「いちばん遅い」が文書と歌詞シートのなかで実際に何でできているのかを問います。

まず範囲についてお断りします。読んだのは、アルバム企画書、曲の設計書(歌詞シートと Suno のスタイル欄)、音楽制作パッケージ、制作ログです。サウンドについて述べることはすべて、それらの文書に書かれた仕様であり、聴いた印象ではありません。録音が仕様どおりに聞こえるかどうかは確認していません。実際に歌われている部分が歌詞シートより短いこともありえます。そして、いつもどおりお伝えします。音楽は AI(Suno)で制作しています。歌詞は AI が下書きし、人が確認しています。

## 「いちばん遅い」が書かれている場所

「いちばん遅い」という言葉(韓国語では 가장 느린)は、2つの文書に出てきます。曲の設計書のメモには、こうあります(私たちの訳)。

> いちばん遅いテンポ(64 BPM)、いちばんミニマルな Ambient Piano で、アルバム全体を静かに閉じる。

アルバム企画書のサウンドデザインの流れにも、同じ方向を指す一行があります(私たちの訳)。

> Ambient Piano — いちばん遅い64 BPM、ミニマル、アルバムを静かに封じる

曲の設計書の冒頭にある情報表では、この曲は「アルバムのクロージング(最後の曲)」(私たちの訳)とされ、核となる感情は安らぎ(peace)です。アルバム企画書の概要表は、アルバムのジャンルを一行で示し、括弧で1つだけ例外を添えています(私たちの訳)。「Ambient Lo-fi(Sleep / Warm / Emotional Chill、クロージングは Ambient Piano)」。10曲がひとつのジャンル名の下に並び、最後の1曲だけが別に名指しされています。

![10曲のテンポを点と棒で示したグラフ。01は68から72、02は70、03は72、04は74、05は66から70、06は70、07は72、08は68、09は72、10は64。トラック10は金色で縁取られ、09から10への線は8 BPM下がる。下の行には、共感と理解から、休息と感謝を経て、安らぎまで、各曲の感情名が韓国語で並ぶ](/assets/journal/closing-with-the-slowest-song/tempo-ladder.jpg)

*10曲のテンポ。各曲の設計書のテンポ欄から書き写したもの。*

グラフが示すとおり、テンポは少しずつ下がっていくわけではありません。いちばん速いのは04の74 BPMで、05で66〜70に下がり、07と09で72に戻ります。64は10曲のなかで最も低い値で、その次に低いのは66、05に書かれた範囲の下限です。曲と曲のつなぎ目を見ると、09から10への段差、72から64は8 BPMです。04から05への段差は、設計書の66〜70という範囲を使えば4〜8 BPMで、同じ大きさかもしれません。05の制作パッケージのスタイル文に書かれた68を使えば6 BPMです。この2つを除くと、ほかのつなぎ目はどれも4 BPM以下です。要するに、書類の上では、アルバムは70前後を上がったり下がったりしたあと、最後のつなぎ目で一度だけ大きく下がります。

注意点が2つあります。テンポ欄は、曲を作るときに私たちが求めた値であり、完成した音源で測ったテンポではありません。また01の制作パッケージには「70 BPM前後のスローテンポ」とあり、1曲のなかでさえ、文書がいつも同じ形で値を示すとは限りません。10については、設計書、パッケージの表、スタイル文のすべてが64と書いています。

## 遅いだけではない — ギターが去る

![10曲のジャンル欄、ギター系の楽器、楽器欄の雨とアンビエンスの項目、ミックス欄の最後の文言を並べた表。01から09はそれぞれ Warm Guitar、Gentle Guitar、Warm Nylon Guitar、Warm Acoustic Guitar のどれかを挙げ、ギターの欄が空なのは10だけ。10のジャンル欄は Ambient Piano と Sleep Lo-fi、楽器欄の雨と夜の項目は Light Rain と Very Soft Night Ambience、ミックスの文言は Very Soft Dynamics](/assets/journal/closing-with-the-slowest-song/sound-spec-ten.jpg)

*10曲のサウンド仕様。曲の設計書の Genre・Instruments・Mix 欄から読み取ったもの。*

曲の設計書で、10の楽器欄は Felt Piano、Warm Pads、Soft Ambient Strings、Vinyl Crackle、Light Rain、Very Soft Night Ambience となっています。この一覧は前の記事にも出てきたので、ここでは最初の9曲と並べます。

いちばん目につくのは、ないものです。01から09には、それぞれギター系の楽器が1つずつ挙げられています。01・02・04は Warm Guitar、03は Gentle Guitar、05と08は Warm Nylon Guitar、06・07・09は Warm Acoustic Guitar です。10の楽器欄にはギターがありません。アルバム企画書の共通の質感の一覧は「Felt Piano · Warm Guitar/Pads · Vinyl Crackle · Warm Analog Tone · Wide Reverb」で、そこに Warm Guitar が入っていますが、その一覧に照らしてギター系の楽器がないのは最後の曲だけです。ジャンル欄も同じです。01から09は、ジャンル欄がすべて Ambient Lo-fi で、10は「Ambient Piano · Sleep Lo-fi」と、Ambient Lo-fi という名前がありません。アルバム企画書の括弧は、曲の設計書でも裏づけられます。

だからといって、楽器が少ないわけではありません。10の楽器欄は6項目で、7項目の09より少ないものの、03から08の6項目と同じです。「ミニマル」は数ではなく構成で読む必要があります。ギターがなく、ジャンル名の先頭にピアノがあり、ミックス欄の最後の文言が「Very Soft Dynamics」であること。ほかの曲の同じ位置は、「Soft Dynamics」(03と08)、「Minimal Dynamics」(04と06)、「Very Gentle Compression」(05)、「Gentle Compression」(09)です。強さを示す文言で「Very」がつくのは、05と10だけです。

楽器欄の雨とアンビエンスの項目は、もう1つ別の話を足してくれます。アルバム企画書のサウンドデザインの流れは「夜 → 朝」(私たちの訳)と題され、アルバム全体が「一日の夜から翌朝へ」(私たちの訳)進むと書かれています。その流れのなかで、09は「Morning Birds (very subtle) + Rain Fade Out」(私たちの訳、一部)で、「夜が明けはじめる」(私たちの訳)ところです。09の設計書の楽器欄にも、Morning Birds (Very Subtle) と Rain Fade Out があります。ところが、その次の10は、楽器欄で夜の音に戻ります。Light Rain と Very Soft Night Ambience です。歌詞もその側にあります。韓国語版では、Verse 1 のささやきが「Good evening...」で、Outro の最後の言葉は、署名の前の「Good night.」です。では、朝はどこへ行ったのでしょう。歌詞はこう受け渡します。

> 今日の心配は今日に置いて、明日の希望は明日会おう。

夜の音のうえで、朝を明日に預ける一文のように読めます。これは、仕様と歌詞を並べて得た読みです。サウンドの流れが09で朝に着き、10で夜に戻ることを意図していたのかは、記録にありません。

## 行も短く切れる

![10曲の韓国語歌詞の1行あたりのハングル平均文字数を示す横棒グラフ。01は6.61、02は5.48、03は6.63、04は6.31、05は6.14、06は5.71、07は6.32、08は5.41、09は5.62、10は5.29で、最も短く、金色で描かれている。右側には、ハングルを含む行数が54、54、78、78、64、75、65、76、66、69と並ぶ](/assets/journal/closing-with-the-slowest-song/line-length.jpg)

*韓国語の歌詞シートの1行あたりのハングル平均文字数。ハングルのない行(英語のささやき、「Good night.」、署名)は除き、「속삭임」(「ささやき」)というラベルは歌詞の文字として数えていません。行数もそれらの英語の行を除いた値です。*

テンポが遅いからといって、行が短くなる決まりはありません。それでも数えてみると、10は短い側にあります。韓国語シートのうちハングルを含む行を取ると、10の平均は1行5.29文字で、10曲のなかで最も短くなります(「속삭임」、つまり「ささやき」というラベルは歌詞の文字として数えていません)。最も長いのは03の6.63で、10の次に短いのは08の5.41と02の5.48です。同じ数え方を英語版でやると、10の1行平均は3.49語です。そちらでは08(3.37)と06(3.45)のほうが短く、10は10曲中3番目になります。つまり、短さは韓国語シートでははっきりしていて、英語では弱いのです。3文字以下のごく短い行だけを数えると、最も多いのは08の27行で、10は20行です。グラフが示すのは平均という1つのことだけです。行は、歌詞シートが文章を区切る単位であり、音源で行がどう歌われているかは確認していません。

行の区切りがいちばんよく見えるのは、最も繰り返される文です。Verse 1 は、こう始まります。

> 오늘도
> 정말 고생했어.

(おおよそ「今日も / 本当によくがんばったね。」)오늘도 という1語が、丸ごと1行を占めます。Chorus の最初の行では、同じ語に省略記号(…)がつきます。

> 오늘도...
> 정말 고생했어.

この省略記号は、この曲で注目したい2つ目の印です。「오늘도...」は、Chorus と Final Chorus に2回出てきます。ささやきの行の省略記号(「Good evening...」「You did enough...」「Sleep well...」)を除いて、主な行だけを数えると、10曲全体で省略記号のある行は、03(Verse 2、「그런데...」)、05(Verse 1、「잠깐...」)、06(Verse 2、「나...」)に1つずつと、10のこの2つです。1曲に2つあるのは10だけで、省略記号が Chorus のフック、つまりこの曲のタイトルになっている行にあるのも10だけです。10のタイトルのなかで、省略記号を含むのはこの曲だけです。英語版も、同じ場所で「You really…」と同じことをしています。ほかの曲のタイトル行は、ピリオドか疑問符で閉じられていますが、この曲のタイトル行だけは、文を言い終えずに、続く前の休みとして印がつけられています。その休みが音源でどれだけの長さに聞こえるのかは、確認できませんでした。歌詞シートで確かめられるのは、省略記号が置かれた場所です。

## 感謝が Outro を離れる

韓国語シートで語幹の 고마(「感謝」)を検索すると、場所が分かれます。

| 曲 | 感謝のあるセクション | 感謝を述べる行(韓国語) |
|---|---|---|
| 01 | Outro | 오늘도 / 여기까지 와줘서 / 고마워. |
| 02 | Outro | 오늘도 / 잘 버텨줘서 / 고마워. |
| 03 | Outro | 오늘도 / 조용히 버텨줘서 / 고마워. |
| 04 | Outro | 누군가의 하루를 / 조금 더 따뜻하게 만들어줘서 / 고마워. |
| 05 | なし | |
| 06 | Outro | 오늘도 / 같은 하루를 살아줘서 / 고마워. |
| 07 | Final Chorus と Outro | 오늘도 / 내 곁에 있어줘서 / 고마워.(Final Chorus には 「오늘도 / 고마워.」) |
| 08 | Outro | 오늘도 / 여기까지 와줘서 / 고마워. |
| 09 | なし | |
| 10 | Final Chorus | 고마워. / 오늘을 / 끝까지 살아줘서. |

どこかに感謝がある8曲のうち、Outro にないのは10だけです(07は Outro にもあります)。01との位置の違いは前の記事で指摘したので、ここでは表の最後の列を読みます。01〜04と06〜08では、理由のついた感謝の文は一方向に進みます。先に理由を述べ、「고마워.」で閉じます。おおよそ、「ここまで来てくれてありがとう」「よく耐えてくれてありがとう」「そばにいてくれてありがとう」です。10では、その順序が裏返ります。「고마워.」が先にあって、ピリオドで終わり、そのあとで「오늘을 끝까지 살아줘서」(「今日を最後まで生きてくれて」)が理由として続きます。その理由の行は、서 で終わる断片なので、理由の節は、曲がささやき「Sleep well...」へ進むなか、主節を欠いたまま残されます。

英語で変わるのは、順序ではなく文の終わり方です。ほかの曲では、感謝は1つの文です。01は「Thank you for making it this far today.」、08は「Thank you for making it this far today too.」で、歌詞シートでは3行に分かれていても、ひと続きの1文として流れます。10では「Thank you.」がピリオドで閉じられて独立し、「For living this day all the way through.」が断片として続きます。英語では、ほかの曲でも「Thank you」が先に来るので、順序は裏返っていません。10で違うのは、感謝がピリオドで終わって単独で立ち、理由が断片として続くことです。

では、Outro は何をしているのでしょうか。そこには、先に引用した「今日の心配は今日に置いて、明日の希望は明日会おう。」という行があり、続いて「穏やかな夜があなたを温かく包みますように。」と「Good night.」があります。感謝の代わりに、一日をおろす言葉と、夜を願う言葉が Outro を満たしています。感謝を Outro から出したのが最後の曲だけの設計なのか、別れのためにこの Outro を空けるやり方なのかは、記録にありません。歌詞シートが示すのは、Outro に感謝がないのが05、09、10であること、そしてこの3曲のうち曲の中に感謝があるのは10だけであることです。

## 記録にないこと

- 最後の曲がなぜいちばん遅く設定されたのか。設計書には64 BPMと「アルバム全体を静かに閉じる」(私たちの訳)という狙いが書かれていますが、なぜ64なのかには何も答えていません。
- ギターを外したのが意図だったのか、そして10の夜の音がなぜ09の朝の音のあとに来るのか。
- 音源の実際のテンポと実際のアレンジ。テンポ、楽器、ミックスの文言はすべて求めた仕様で、Suno が書かれたとおりに作ったかどうかは確認していません。
- 歌詞がどう書かれ、どう直されたのか。10の制作ログには、歌詞が AI の下書きを人が確認したものだということしかなく、修正欄には自動で入ったプレースホルダーのメモがあるだけです。

## 聴く
